# Responsive Landing Page

# About the Project
This project is a responsive landing page developed as part of the CodeOrbit Tech Frontend Development Internship. It focuses on creating a clean and attractive webpage that works across different screen sizes.

# Features
- Navigation bar
- Hero section with heading and description
- Call-to-action button
- Responsive layout
- Hover effects and CSS transitions
- Support for mobile, tablet, and desktop screens

# Technologies Used
- HTML5
- CSS3
- JavaScript

# Project Structure

CodeOrbit_ResponsiveLandingPage/
├── index.html
├── style.css
├── script.js
└── README.md


# How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your web browser.
4. Test the layout at different screen sizes.

# Purpose
The purpose of this project is to practice responsive web design using CSS Flexbox or Grid and create a user-friendly landing page.
